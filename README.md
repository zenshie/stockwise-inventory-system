# Stockwise Inventory Management Demo
Open `index.html` in a browser, or deploy this folder using GitHub Pages.
## Features
- Dashboard with inventory counts, cost valuation and stock alerts
- Product catalog with SKU, optional barcode, category, cost, selling price, quantity, reorder level and supplier
- Add, edit and delete products
- Stock-in, stock-out and set-quantity adjustments
- Stock movement history with reason/reference
- Supplier directory
- Inventory valuation report and CSV export
- Browser localStorage persistence
## Demo limitations
This is a front-end demonstration only. Data is saved in the current browser and is not synchronized across devices. It has no authentication, backend database, purchase order workflow, barcode scanner integration, accounting integration, automated notifications or cloud backup. The sample records are fictional. Do not enter real business information or rely on this demo for official accounting or stock records.
## GitHub Pages
Create a repository, upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root, then choose Settings → Pages → Deploy from a branch → `main` → `/(root)`.
